# UX 全面优化设计方案

## 概述

对 LinguaLeap 平台进行全站用户体验优化，涵盖视觉体验、交互体验、功能体验三个维度。采用**按页面分批推进**策略，第一批聚焦 5 个核心页面。

## 实施策略

- **方案**: 按页面分批推进（方案 A）
- **优先级**: 视觉 → 交互 → 功能
- **第一批**: Home、Auth、Courses、WordLearn、Progress

## 全局组件优化

### 新增组件
- `Skeleton` — 骨架屏加载组件
- `EmptyState` — 空状态组件（插画 + 引导）
- `ErrorState` — 错误状态组件（重试按钮）
- `ImageWithFallback` — 图片加载组件（模糊占位 → 渐入）
- `AnimatedNumber` — 数字滚动动画组件
- `ParticleBackground` — 粒子背景组件

### 优化组件
- `Navbar` — 响应式优化，移动端手势
- `Toast` — 增加更多类型（成功/错误/警告/信息）
- `LoadingSpinner` — 增加进度百分比显示
- `Tooltip` — 增加延迟显示/隐藏

## 设计系统统一

### CSS 变量标准化
- 统一标题大小层级（h1: 5xl-6xl, h2: 3xl-4xl, h3: 2xl）
- 统一卡片圆角（大卡: 2rem, 中卡: xl, 小卡: lg）
- 统一间距体系（基于 4px 网格）
- 统一过渡时长（短: 200ms, 中: 300ms, 长: 500ms）

### 动画规范
- 统一缓动函数: `cubic-bezier(0.22, 1, 0.36, 1)`
- 统一 spring 参数: `stiffness: 200, damping: 20`
- 页面入场: `opacity + y + blur`
- 列表入场: `staggerChildren` 交错
- 交互反馈: `whileHover`/`whileTap` 缩放
